Engineering Academic Mini Project

Smart Government Scheme Eligibility Checker Using Natural Language Processing

Short Name: GovScheme NLP

Project Purpose

GovScheme NLP is an easy-to-understand, web-based Natural Language Processing application designed for engineering students. It allows citizens to describe their demographic details, financial background, and specific assistance requirements in normal natural language. The system extracts structured attributes and evaluates them against curated Indian government scheme criteria.

NLP Concepts Demonstrated
  • Tokenization & Segmentation: Sentence splitting and word tokenization using NLTK.
  • Morphological Analysis: Stop-word removal, Porter Stemming, and WordNet Lemmatization.
  • Part-of-Speech Tagging: Grammatical tagging (Nouns, Verbs, Adjectives).
  • Spelling Correction: Minimum Edit Distance (Levenshtein) against domain vocabulary.
  • N-Gram Analysis: Unigrams, Bigrams, and Trigrams phrase extraction.
  • Semantic Normalization: Synonym mapping for canonical occupations, social categories, and need types.
  • Information Retrieval: TF-IDF Vectorization and Cosine Similarity matching via scikit-learn.
  • Rule-Based Eligibility Evaluation: Explainable criteria comparison engine.
Technology Stack
Backend Stack: Python 3.13 Flask NLTK scikit-learn spaCy
Frontend Stack: HTML5 CSS3 Bootstrap 5 Vanilla JS Chart.js
Academic Disclaimer: This project uses a limited, curated dataset for academic demonstration. Government scheme eligibility, benefits, documents, and application procedures change frequently. Always verify current information through official government portals.
